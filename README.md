# Simulador de Inversiones

Este es un simulador de inversiones interactivo que permite a los usuarios calcular y visualizar el crecimiento potencial de sus inversiones a lo largo del tiempo.

## Características

- Cálculo de inversiones con aportes mensuales
- Visualización gráfica de resultados
- Tabla detallada de proyecciones
- Interfaz interactiva con sliders
- Resumen de resultados en tiempo real

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js para gráficos
- TailwindCSS para estilos
